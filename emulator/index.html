Baerilog: Emulator

Use ROM images from Uzebox (https://github.com/Uzebox/uzebox)

▾ROM

Load a .uze or .hex ROM — e.g. compiler/uzebox/tools/packrom/Test/arkanoid.uze.

▾Console

Program output on UDR0 in green — the USART is where Uzebox firmware sends printf. Emulator messages are grey.

▾Core

Progress counters for the running machine — pc, SP and SREG live in the Registers card

▾Disassembly

Instructions decoded from flash — a window around the current pc, since the ROM is 28,479 words. Click an address to set a breakpoint.

Load a ROM to see its disassembly.

▾Registers

ATmega644 register file at the current position — a green → shows the value the highlighted instruction is about to write, and an amber name a register it reads

Load a ROM to see the register file.
